# ระบบติดตามระดับน้ำและแจ้งเตือนภัยน้ำท่วม 
**งานศูนย์ป้องกันและบรรเทาสาธารณภัย เทศบาลนครนครราชสีมา**

ระบบ Dashboard ติดตามสถานการณ์น้ำลุ่มน้ำลำตะคอง ฝนสะสม และวิเคราะห์ความเสี่ยงภัยน้ำท่วมสำหรับ 6 กลุ่มชุมชนในเขตเทศบาลนครนครราชสีมา

## รายชื่อสถานีวัดระดับน้ำ
1. **M177:** บ้านลาดบัวขาว ต.ลาดบัวขาว อ.สีคิ้ว จ.นครราชสีมา
2. **M192:** บ้านโนนค่า ต.บุ่งขี้เหล็ก อ.สูงเนิน จ.นครราชสีมา
3. **M191:** บ้านโคกกรวด ต.โคกกรวด อ.เมืองนครราชสีมา จ.นครราชสีมา
4. **M164:** ตำบลในเมือง อ.เมืองนครราชสีมา จ.นครราชสีมา

## รายชื่อกลุ่มชุมชนเฝ้าระวัง
1. ชุมชนมิตรภาพ ซ.4 / คุ้มวงษ์
2. ชุมชนบุมะค่า / สำโรงจันทร์ / ท่าตะโก
3. ชุมชน VIP
4. ชุมชนเกษตรสามัคคี
5. ชุมชนหลังวัดสามัคคี, อบอุ่นพัฒนา
6. ชุมชนวัดศาลาลอย / ท้าวสุระ / มหาชัย
